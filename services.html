SERVICES


Below are Eclipse's Services ranging from software services for enterprises to softwares for the individual person.

Apollo Software is an all in one Enterprise Resource Planning and Operations suite designed specifically for mid-to-large scale businesses that need to unify their data, design and development workflows.

Apollo Software For Enterprises

The Future of all-in-one Enterprise Resource Planning and Operations Suites

Unlike the standard modular software, Apollo is built on a "single pane of glass" philosophy which means your management, creative and technical teams all work in the same environment.

Apollo Nexus

Data and API management.

A robust SQL-based backend that manages massive inventories and client databases. It features native API connections to link your existing tools like slack, salesforce or AWS into one dashboard.

Apollo Canvas

Creative Suite

An integrated design workspace for branding and UX/UI prototyping. It allows marketing teams to create assets that developers can immediately pull into live code environments.

Apollo Horizon

Project and Notion Sync

Advanced project management that uses a "Notion-style" flexible database system. It handles sprint planning, automated reminders and client portals.

Apollo Shield

Cybersecurity

A zero trust security layer that monitors login patterns and encrypts sensitive business data at rest and in transit.

Technical Requirements - Server Side

To ensure the software runs at peak performance
-Processor: Minimum 8-core CPU (for high-concurrency data processing).
- RAM: 32GB (64GB recommended for high-volume SQL environments).
- Storage: SSD with at least 500GB of available space for localized caching.
- OS: Compatible with Linux (Ubuntu/CentOS), Windows Server 2022, or macOS Server.

Technical Requirements - Client Side

To leverage the AI and design features of Apollo, team members should use hardware capable of local processing:
- Recommended Devices: MacBook Air/Pro (M2 or newer), Microsoft Surface Laptop 7, or Lenovo ThinkPad X1 Carbon.
- NPU Requirements: For AI-assisted automation, an NPU (Neural Processing Unit) capable of 40+ TOPS is preferred.
